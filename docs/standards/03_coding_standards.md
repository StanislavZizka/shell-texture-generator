# Coding Standards

## Rules
- Use type hints for public functions and dataclasses.
- Keep numerical code side-effect free where possible.
- Keep I/O separate from computation.
- Keep route handlers thin.
- Prefer small composable services over ad hoc helper chains.

## Conventions
- Use descriptive names for presets and experiment records.
- Add docstrings to public functions.
- Keep Python and JS code formatted consistently.
