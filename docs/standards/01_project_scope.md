# Project Scope

## What This Repository Does
- Reproducible shell texture generation from reaction-diffusion style models.
- Deterministic or seed-controlled experimental runs with saved metadata.
- Web generation, batch generation, export, and evaluation for thesis use.

## What This Repository Does Not Do
- It is not a generic visual effects sandbox.
- It is not a notebook-only research scratchpad.
- It does not keep important simulation logic only in route handlers.

## MVP
- Core simulation pipeline.
- Preset loading from versioned files.
- Texture export to PNG.
- Experiment records and metrics.
- Automated tests and CI.
